# المفكر · تطبيق القدرات (iOS / Theos)

تطبيق آيفون بيعرض إصدارات المفكر الخمسين، كل إصدار ٤٨ سؤال، وكل سؤال مربوط بشرحه على يوتيوب بنفس التوقيت.
مبني بـ **Theos** (Objective-C + UIKit + PencilKit) ويطلع **IPA**.

## المميزات

- **٥٠ إصدار × ٤٨ سؤال** — شبكة إصدارات مع تقدّم كل إصدار (`١٢ / ٤٨`).
- **ملف الإصدارات مرفق داخل التطبيق** (`Resources/almufakkir-editions.pdf`) — ٢٤٥٠ صفحة = ٥٠ إصدار × (غلاف + ٤٨ سؤال)، فيشتغل التطبيق ويعرض الصفحات من أول تشغيل بدون أي إعداد. تقدر بعد تستورد ملفك الخاص لأي إصدار ويصير بديلاً.
- **عرض صفحة السؤال** من الملف، بتكبير وتحريك بإصبعين.
- **قلم فوق السؤال** (PencilKit) — finger أو Apple Pencil، والرسم محفوظ لكل سؤال على حدة، ما يروح لو طلعت ودخلت أو غيّرت السؤال.
- **زر «▶ الشرح»** يفتح فيديو الإصدار على يوتيوب من **نفس ثانية السؤال**.
- **حفظ الموقع**: كل ما تدخل إصدار يفتح على آخر سؤال وصلت له.
- **علامة إنجاز للإصدار** (✓) + علامة «تم» لكل سؤال، ولما تخلّص ٤٨ سؤال تاخد الإصدار علامة تلقائي.
- **تصحيح التوقيتات**: تعدّل توقيت أي سؤال، أو تزيح كل التوقيتات (`+30` / `-30` ثانية)، أو ترجّع التقديري.
- **ضبط الصفحات**: مع الملف المرفق الصفحة محسوبة تلقائيًا (سؤال q في الإصدار N ← صفحة `(N-1)*49 + 1 + q`). ولمّا تستورد ملفك الخاص تقدر تظبط عدد الأسئلة في الصفحة وأول صفحة وصفحة أي سؤال.

## بناء الـIPA

### على Mac (Theos)

```bash
brew install ldid xz make
git clone --recursive https://github.com/theos/theos.git ~/theos
THEOS=~/theos ./scripts/make-ipa.sh
```

بيطلع `XnfAlMufakkir.ipa` في جذر المشروع. الملف **غير موقّع** — وقّعه بـ Sideloadly / AltStore / TrollStore.

### بدون Mac (GitHub Actions)

من صفحة الـrepo: **Actions → Build IPA → Run workflow**.
لما يخلص، نزّل الـartifact `XnfAlMufakkir-ipa` وجوّاه `XnfAlMufakkir.ipa`.

## مصادر البيانات

- `tools/build_editions.py` يجيب الفيديوهات من بلاي ليست «اصدارات المفكر» (`PLENUCyfnKyFs`)، ويطابق رقم الإصدار من **عنوان الفيديو** (مش من ترتيب البلاي ليست)، ويكتب `Resources/editions.json`.
- تأكيد المطابقة: ٥٠ فيديو، إصدارات ١→٥٠ بدون نقص ولا تكرار.
- **التوقيتات تقديرية**: يوزّع الـ٤٨ سؤال على مدة الفيديو. الفيديوهات نفسها ما فيها فصول/توقيتات للأسئلة. صحّح أي توقيت من التطبيق (قائمة الأسئلة ← ضغطة طويلة على السؤال ← تعديل التوقيت).

## ملف الإصدارات

الملف المرفق مع المشروع (اللي رفعه صاحب التطبيق) اسمه `Resources/almufakkir-editions.pdf`، وTheos يضمّنه داخل الـ`.app` تلقائيًا لأنه داخل `Resources/`.
تحققنا من تركيبه برمجيًا: ٢٤٥٠ صفحة، و٥٠ غلاف بالضبط على الصفحات `1 + 49k` (يعني كل إصدار ٤٩ صفحة: غلاف + ٤٨ سؤالاً بالترتيب).

الاستيراد اليدوي (`استيراد ملف الإصدار`) باقي موجود لو بينك ملف أفضل أو نسخة ثانية — الملف المستورد يأخذ أولوية على المرفق، وإزالته ترجّعك للمرفق.

## البنية

```
Makefile                      بناء Theos
Resources/Info.plist          معلومات التطبيق
Resources/editions.json       بيانات الـ٥٠ إصدار + روابط يوتيوب + التوقيتات
Resources/almufakkir-editions.pdf  ملف الإصدارات المرفق (٢٤٥٠ صفحة)
main.m, MFAppDelegate.*       نقطة البداية
MFStore.*                     حفظ الحالة (آخر سؤال، المحلول، الصفحات، التوقيتات، الرسومات، ملفات PDF)
MFEditionsViewController.*    شبكة الإصدارات + علامة الإنجاز
MFQuestionViewController.*    صفحة السؤال + القلم + زر يوتيوب
MFQuestionListViewController.* قائمة الأسئلة ١–٤٨
MFEditionCell.*, MFPDFPicker.*, MFTheme.*, MFEdition.*
tools/build_editions.py       مولد بيانات الإصدارات
scripts/make-ipa.sh           بناء IPA محليًا
```
